## Reading against the PREREG

- **H0** (at least half of bounded programs have redundancy > 0.5 bit): 4 of 7.
  Inconclusive at N = 7, and three of the four (17, 51, 52, 57: four programs, all
  with redundancy > 0.5) are a case the PREREG did not anticipate: a program
  whose steps never emit and never refuse has exactly one behaviour whatever
  its state, because nothing outside the program observes it. Their examples
  assert on internal state (`light == Yellow`), which is a test, not an output
  of the Form (spec 6.9 vs 6.1). That is the definition working, and it is the
  finding of this pilot: **the corpus's state machines are mostly unobservable**.
  The frozen run must stratify by "emits or refuses on some path" before H0 is
  tested, and the spec text of 10.11 now says this in words.
- **H1** (single-emit-site programs have higher redundancy): not testable here;
  the bounded set has no program with several emit sites.
- **H2** (per-region attribution): holds on every bounded row with redundancy > 1
  (one region carries all of it), N = 4.
- A definitional error in the engine was found and fixed by this pilot: the
  first control label recorded which regions changed, which is not a function
  of the output, and gave dim_c = 4 > dim = 1 on example 51. The label is now
  the refusal or the emitted constructors only; `dim_c <= dim` holds on every row.
