# Frozen Form benchmark

`PREREG.json` was committed before any result. Three programs from
`crates/joule-sales-outreach` are re-expressed as Forms (`b*.rce` +
`b*.fit.json`, both generated by `gen_forms.py`).

- `harness/` holds the driver that runs the **original** code verbatim
  (a copy of the crate whose `Cargo.toml` only drops workspace
  inheritance) on the preregistered seeded inputs; its output is
  `recorded/*.jsonl` (`{"input", "output"}` per line).
- `tests/form_bench.rs` replays every recorded input through the Form
  reference δ (b3 closed-loop: the Form's own previous status is its next
  input) and the first 200 events through the generated Rust, Python and
  XState projections, which must print the reference trace byte for
  byte. `RCE_BENCH_WRITE=1` rewrites `RESULTS.json`;
  `RCE_BENCH_ORIGINAL_SRC=DIR` points at the original crate when it is not
  at `../joule-sales-outreach` (LOC is reported only if its hash matches
  the preregistration).

Read RESULTS.json with its limits: est_j values are estimates from the FGIR
instruction table, and there is no est_j for the original. The fit is
generated JSON, so its line count is not authored code. Agreement
covers the outputs listed in the prereg; b3 compares only `status`.
`b3full` (a dated amendment to the prereg, recorded after b1-b3 were
known) compares every field the transition methods write — status,
current_step_id, next_step_at, step_history length, and whether
`updated_at` was written (wall-clock, so a flag) — with the Form keeping
each enrollment's row and its rule reading it back (fit `reads`). u64 inputs above
i64::MAX fall outside the Form's int, and the out-of-domain probe shows
the contract rejects them.
