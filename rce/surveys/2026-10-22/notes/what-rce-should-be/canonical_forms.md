# Canonical forms of program behavior and equivalence checking — design input for the Form P=(S,E,δ,D,λ)

Grounding used (read before any web search): the RCE paper (research.openie.dev/papers/rce, sections 3, 3.6, 5), `spec/book/07-form-evaluation.md` §6.1/6.1.1, `spec/book/08-steps-loops-concurrency.md` §6.6–6.7, `spec/book/10-theorems.md`, `spec/book/17-draft09.md` F.4.3, `spec/proposals/form-ir-2.md`. Relevant facts from the spec that the web findings are measured against:

- δ : S × E → S × O\* is total (T2, proved in Lean with an explicit step bound), deterministic (T1), pure; λ = π₂ ∘ δ; D is a SHA-256 hash chain over canonical JSON (§6.1). State is the fold of the log (T3). A refused event leaves state unchanged (T8).
- Bounds: LOOP_LIMIT = 1,000,000 default (module may override, §6.7); SIZE_LIMIT = 1,000,000 elements; VALUE_LIMIT = 1,048,576 bytes of canonical JSON per state value (N9). Integers are i64/u64 with checked overflow; floats are finite binary64. So S is finite but astronomically large: a single i64 field alone has 2^64 values, and a state value may be up to 1 MiB of canonical JSON.
- Name-freeness: identifiers are replaced by De Bruijn positions before hashing (§6.6, T7 proved: renaming leaves every log hash and id unchanged). F.4.3 defines a *definition hash* as SHA-256 of the canonical encoding of the name-free form plus signature/contracts; "a body changes under an unchanged signature, contracts and measure" is classed *compatible*, i.e. the definition hash is a hash of *syntax modulo names*, not of behavior. T50 ("two definitions with equal hash have equal meaning") is stated, unproved — and note it is only the trivial direction (syntactic identity ⇒ semantic identity); the converse is what a canonical form of behavior would give.
- Paper §3.6: "The canonical serialization of the Form is injective" (distinct Forms ⇒ distinct shape hashes). Paper §5.2: every built-in e-graph rewrite is proved in Z3; "A proposed equivalence enters the e-graph only with a proof." Paper §5 does not claim canonical equivalence of programs (per the fetched text).
- form-ir-2.md: content-addressed `defs` keyed by SHA-256 of canonical JSON of the body; the e-graph treats a `ref` as an opaque leaf and inlines only bodies ≤ INLINE_MAX nodes; float rewrites are never admitted (N-8).

Hypothesis under test: "every bounded Form is a finite Mealy machine; the minimal machine under name-free labeling is a canonical form of behavior." Verdict in brief: the first clause is a theorem (trivially, given T1/T2/N9 and finite E-payloads, but see the caveat that E is *not* finite as specified); the second clause is true in theory (minimal complete deterministic Mealy machines are unique up to isomorphism, and BFS canonical numbering turns "up to isomorphism" into a unique string, hence a unique hash) but is *not computable at RCE's state sizes* by explicit enumeration, and the symbolic alternatives either have exponential worst cases (symbolic automata over i64 predicates), or lose uniqueness (register/nominal automata only recover it under "well-typed" restrictions on how data is used), or are only semi-decision/bounded procedures (Alive2, Hobbit, e-graphs). The practical recommendation is a layered scheme: a *syntactic* shape hash (what exists today), a *bisimulation-quotient* shape hash over the control component Σc with data abstracted to predicates (a decidable, unique canonical form for the finite-control fragment), and e-graph/SMT equivalence as a proof-carrying *partial* canonicalization for the data component Σd — never claiming a complete canonical form for the full Form.

## Key Question 1: Classical theory — Myhill–Nerode, Moore 1956, Hopcroft, Mealy minimization, and name-free canonical labeling

### Takeaway
For complete, deterministic machines the minimal machine exists, is unique up to isomorphism, and is computable in O(k·n log n) (Hopcroft); a fixed-traversal canonical numbering (initial state = 0, then first-visit order over the alphabet in a fixed order) converts "unique up to isomorphism" into a unique string, so SHA-256 of that string is a canonical hash of behavior. Everything hinges on three adjectives — *complete*, *deterministic*, *finite alphabet* — and on explicit enumeration of states; RCE has the first two by theorem and lacks the third in the way it matters.

### Cited Findings
- **Minimal DFA uniqueness and ICDFA canonical string.** Reis, Moreira, Almeida (Univ. Porto, 2005; DCFS / TR DCC-2005-04) define an initially connected DFA (ICDFA) as one where every state is reachable from q0, and give a canonical string: initial state numbered 0, the next state is "the first one to be referred (excepting q0) by a transition from q0", each later state is the next *new* state referenced from states already numbered, with symbols in a fixed order σ0 < … < σk−1; the string is [(Si)i<kn], Si = δ(⌊i/k⌋, σ_{i mod k}). Theorem 1: "there is a one-to-one mapping between strings satisfying R1 and R2 and the non-isomorphic ICDFA structures with n states over k symbols" (two automata with the same string are isomorphic, and isomorphic automata yield the same string). The paper also states that minimal DFAs are unique up to isomorphism, every minimal DFA is an ICDFA, and the canonical form is used in FAdo to test isomorphism of minimal DFAs — [Reis–Moreira–Almeida, On the Representation of Finite Automata](https://www.dcc.fc.up.pt/~nam/resources/publica/dcfsrma05.pdf). The combined claim "minimize, then canonical-number, gives a unique representative of the language" is an inference from these points, not stated verbatim in that paper.
- The same group's work on minimal acyclic DFAs (MADFA) uses a rank-based numbering (dead state 0, pre-dead 1, states numbered by rank then lexicographic order of transition tuples) and proves (Theorems 4–5) a bijection between valid strings and non-isomorphic MADFAs — [Almeida–Moreira–Reis, Exact Generation of Minimal Acyclic DFAs](https://www.dcc.fc.up.pt/~nam/resources/publica/ijfcsamr07.pdf). Relevant because an RCE Form run under a finite LOOP_LIMIT with no cycles in Σc is acyclic.
- **Incompletely specified Mealy machines are NP-complete to minimize** (Pfleeger 1973, cited), while fully specified machines are "efficiently solvable"; Renkin, Schlehuber-Caissier, Duret-Lutz, Pommellet (LRDE/EPITA, FORTE 2022) give reductions for incompletely specified generalized Mealy machines where bisimilar states are necessarily merged and their ⊑-based reduction "is always smaller than the bisimulation quotient of the original machine" — [Effective Reductions of Mealy Machines, arXiv:2206.10228](https://arxiv.org/pdf/2206.10228). The uniqueness of a minimal machine up to isomorphism is *not* discussed for the incompletely specified case (minimal machines are not unique there).
- **Hopcroft's O(n log n)** algorithm for DFA minimization (1971) and Moore's 1956 partition-refinement ("Gedanken-experiments") are the standard references; an exposition of Hopcroft's algorithm and its complexity appears in [Xu, Hopcroft's algorithm write-up (IRIF)](https://www.irif.fr/~carton/Enseignement/Complexite/ENS/Redaction/2008-2009/yingjie.xu.pdf) and a course note on DFSM canonical forms at [Rose-Hulman CSSE474, DFSM canonical form](https://www.rose-hulman.edu/class/csse/csse474/202140/Resources/DFSM-Canonical-Form/DFSM-canonical-form.pdf). These two appeared in search results and were not fetched in full; the exact statements (Moore: O(k·n²) by iterative refinement; Hopcroft: O(k·n log n) by "process the smaller half") are standard textbook content (Hopcroft–Ullman) and should be cited from the primary 1956/1971 papers in the final report.
- **Bisimulation quotient = minimal Mealy machine for deterministic complete machines.** The symbolic-bisimulation literature states that signature refinement "computes the coarsest branching bisimulation" (Blom–Orzan, cited in Sigref) — [Wimmer et al., Sigref – A Symbolic Bisimulation Tool Box, ATVA 2006](https://ira.informatik.uni-freiburg.de/~wimmer/pubs/wimmer-et-al-atva-2006.pdf). For a deterministic complete Mealy machine, strong bisimilarity coincides with trace (input/output) equivalence, so the coarsest bisimulation quotient is the Nerode quotient (inference; standard).

### Inferences
- In RCE terms: let Σc be the control component and treat each event type with its payload as a letter. If the payload sets were finite, P with δ total (T2) and deterministic (T1) is exactly a *complete deterministic Mealy machine* M_P = (S, E, O\*, δ₁, λ). Its Nerode quotient M_P/≈ is unique up to isomorphism; applying the Reis–Moreira–Almeida numbering with a fixed total order on E (e.g. the canonical order of §6.1 on {type, payload}) gives a unique string; SHA-256 of that string is a *behavioral shape hash* that is name-free for free (names never enter the string — only state positions and the canonical order of events).
- The hypothesis' first clause needs a correction: as specified, E is **not finite** (payloads include i64, text up to SIZE_LIMIT) and S is finite only because of VALUE_LIMIT. A Form is therefore a finite Mealy machine over an *astronomically large finite* alphabet, not a small one. The classical theory applies in principle, not in practice. The honest statement is: "every bounded Form is a finite Mealy machine with |S| ≤ 256^VALUE_LIMIT and |E| ≤ (number of event types)·256^VALUE_LIMIT."
- Minimality per se is not what gives canonicity; *determinism + completeness + a fixed traversal order* do. RCE's T1/T2 are precisely those two properties, so the theoretical precondition for a canonical form is already a proved theorem of the language. The entire obstacle is computational, which is the subject of Q2–Q4.
- The MADFA result matters for the common case: a Form whose control graph is acyclic under its loop bounds has a rank-based canonical form that is cheaper to compute than the general one.

### Gaps
- I did not fetch primary texts for Moore 1956, Nerode 1958, Hopcroft 1971, or Hopcroft–Karp 1971; their exact complexity statements are standard but should be quoted from the originals by the report writer.
- Mealy-specific canonical-string constructions (Mealy rather than DFA) were not found as a separate published result; the extension (append the output of each transition to the string) is a direct inference from the DFA result.

## Key Question 2: Symbolic minimization at scale — BDD bisimulation, symbolic automata, register/nominal automata for unbounded data domains

### Takeaway
BDD-based signature refinement handles ~10⁹ explicit states only when the state space is highly structured and the quotient is tiny; symbolic finite automata (D'Antoni–Veanes) give a unique minimal automaton "up to equivalence of predicates" in O(n² log n · f(nℓ)) solver calls with no minterm blowup; register automata over equality/order atoms admit Myhill–Nerode and unique minimization only for *well-typed* deterministic automata, and minimality "in states and registers" need not exist in general. None of these gives a unique canonical form for a machine whose transitions compute arbitrary i64 arithmetic.

### Cited Findings
- **Sigref (Wimmer, Herbstritt, Hermanns, Strampp, Becker; ATVA 2006).** Signature-based refinement: start from P₀ = {S}; P_{i+1} = sigref(P_i); stop at fixpoint. States are binary-encoded, the partition stored as P(s,k) with block numbers k, signatures as σ(s,a,k) BDDs. Supports strong, weak, branching and five other bisimulations. Scale: the Kanban LTS with 4,224,876,912 states and 29,070,458,880 transitions reduced to a branching quotient of 68,217 states in 53,725.40 s (a factor of "nearly 62.000"); limits were 160,000 s CPU and 2 GB RAM; "for large instances Sigref requires a huge amount of time." — [Sigref, ATVA 2006](https://ira.informatik.uni-freiburg.de/~wimmer/pubs/wimmer-et-al-atva-2006.pdf). Later multi-core work: [van Dijk & van de Pol, Multi-core symbolic bisimulation minimisation, STTT 2017](https://link.springer.com/doi/10.1007/s10009-017-0468-z) (search result, not fetched).
- **Symbolic finite automata minimization (D'Antoni & Veanes, POPL 2014).** An SFA is (A, Q, q0, F, Δ) over an *effective Boolean algebra* A of predicates. Minimal = deterministic, complete, clean, normalized, with distinct states having distinct languages. Theorem 1: two minimal SFAs over the same alphabet accepting the same language are isomorphic — "unique up to renaming states and up to equivalence of predicates." Theorem 2: quotienting a clean, complete, deterministic SFA by state equivalence yields a minimal SFA. Complexities (n states, m moves, ℓ guard size, f(ℓ) satisfiability cost): Moore-style O(m² f(ℓ)) = O(n⁴ f(ℓ)); Hopcroft-via-minterms O(2^m f(mℓ) + 2^m n log n) with a concrete family where minterms blow up exponentially; symbolic Hopcroft MinN O(n² log n · f(nℓ)) avoiding minterms. The algebra must support satisfiability, ∧, ∨, and (for completion/MinH/MinN) negation. Experiments include SMT-based integer linear arithmetic with divisibility predicates, BDD bit-vector algebras, and a theory of (string, integer) pairs — [Minimization of Symbolic Automata, POPL 2014](https://microsoft.com/en-us/research/wp-content/uploads/2016/02/sfaMinimizationPOPL14.pdf).
- **Symbolic finite transducers (Veanes, Hooimeijer, Livshits, Molnar, Bjørner; POPL 2012).** Theorem 1: "If A and B are SFTs over a decidable label theory then A =1 B is decidable" (1-equality), O(n²·f(m)) with n rules, m rule size, f the label-theory cost; Corollary 1: equivalence is decidable for single-valued SFTs over a decidable theory; full equivalence = domain equivalence (needs complement in the label theory) + partial equivalence. "General equivalence of finite state transducers is undecidable [Griffiths 1968]", "caused by allowing unboundedly many different outputs for a given input." Symbolic transducers *with registers* (Section 3.4): equivalence is undecidable "already for the single-valued case, through direct encoding of 2-counter machines." — [Symbolic Finite State Transducers: Algorithms and Applications, POPL 2012](https://www.doc.ic.ac.uk/~livshits/papers/pdf/popl12.pdf).
- **Automata with group actions / nominal automata (Bojańczyk, Klin, Lasota; LICS 2011).** Corollary 4: "A G-language L is recognized by an orbit-finite G-automaton iff A∗/≡_L is orbit-finite" (Myhill–Nerode carries over). Theorem 3: the syntactic automaton is a homomorphic image of any reachable automaton recognizing L; "our models admit minimization of deterministic automata" independent of signature. Determinization fails: there are languages recognized by orbit-finite nondeterministic automata "not recognized by any deterministic orbit-finite G-automaton." Equality atoms ≡ deterministic finite-memory (Kaminski–Francez) automata (Fact 16); total-order atoms likewise (Fact 17). The *integer signature* (atoms Z with +) is called pathological: uncountably many equivariant functions Z×Z→Z. Theorem 18: the first-order theory of every nominal orbit-finite relational structure is decidable — [Automata with group actions, LICS 2011](https://www.cs.ox.ac.uk/people/bartek.klin/papers/lics11.pdf).
- **Deterministic register automata minimization (Li, Tang, Yen; arXiv 2605.03535, 2026).** Summarizing Benedikt–Ley–Puppis: "every DRA-recognizable language L has a canonical automaton C_L which is the unique minimal well-typed DRA up to isomorphism"; a data language is DRA-recognizable iff its Nerode congruence has finite index; minimization is decidable; equivalence of DRAs is decidable by product/emptiness (no complexity given). But "a minimal DRA need not exist in general because of a trade-off between states and registers" (their Example 25). Hyper-minimal DRAs are not unique. Results target well-typed DRAs over dense ordered or non-ordered domains — [Hyper-Minimization for Deterministic Register Automata](https://arxiv.org/pdf/2605.03535).

### Inferences
- Map to RCE: Σc (control regions, kind variants, booleans, bounded enums) is the "finite-state" part; Σd (i64/u64/f64 fields, text, lists, maps) is the "data" part. D'Antoni–Veanes gives a *unique* canonical minimal machine for the control part **provided the data part is abstracted into a Boolean algebra of guard predicates** (the guards of §6.4 guarded updates) whose satisfiability Z3 decides — exactly the predicate-abstraction move. Uniqueness is only "up to equivalence of predicates", so the canonical hash must hash a *canonical form of the predicate*, not its syntax; for linear integer arithmetic over bounded i64 that is a bit-vector/LIA formula whose canonical form is itself a nontrivial problem (BDD of the bit-blasted guard is canonical for a fixed variable order; a general LIA formula has no cheap canonical form).
- Register-automata results tell RCE exactly which uses of data preserve canonicity: *equality* and *order* comparisons between stored and incoming values (the "well-typed DRA" fragment). The moment δ does arithmetic on i64 (Bojańczyk–Klin–Lasota's "integer signature"), the nominal theory calls the setting pathological and the transducer theory (Veanes et al. §3.4) says equivalence is undecidable for symbolic transducers with registers *before* any bound is imposed. RCE's bounds make it decidable (finite) but do not make it tractable.
- Sigref-scale numbers set expectations: 4·10⁹ explicit states → 15 CPU-hours for a quotient of 7·10⁴. A single i64 field is 4·10⁹ × 4·10⁹. Explicit or BDD enumeration of Σd is out; the only viable route for Σd is predicate abstraction or SMT/e-graph proof per pair.

### Gaps
- Complexity of DRA equivalence (beyond "decidable") was not located in the fetched source.
- I did not find a published symbolic-Mealy (as opposed to SFA/SFT) minimization result stating uniqueness of the quotient with outputs; the SFT single-valued equivalence result plus SFA minimization together cover it by inference only.

## Key Question 3: Program equivalence checkers in practice — Alive2, translation validation, CompCert, Lean/Coq bisimulation, KAT/GKAT/NetKAT, relational verification

### Takeaway
Industrial equivalence checkers are either *bounded and sound-but-incomplete* (Alive2: unroll loops, check refinement in SMT with timeouts, "no false alarms" at the cost of missed bugs), *verified once and for all* (CompCert), or *decision procedures for a restricted algebra of control* (GKAT: equivalence of uninterpreted programs in nearly linear time; KAT: PSPACE-complete). GKAT is the closest thing to a canonical form of *control flow* that is both decidable and cheap, and its automaton model is a deterministic Mealy-like coalgebra of size O(|e|).

### Cited Findings
- **Alive2 (Lopes, Lee, Hur, Liu, Regehr; PLDI 2021).** "Our goal is a zero false-alarm rate, so we err on the side of soundness … which means there are circumstances in which it misses bugs." Bounded: "unrolling loops in the source and target functions by a specified factor"; "will miss refinement failures that require more loop iterations to manifest"; infinite loops unsupported; refinement checked only on paths reaching a return. Relation is *refinement*: "allows a transformation to remove non-determinism, but not to add it"; "In the absence of undefined behaviors, refinement degenerates to simple equivalence." Encoding: integers as bit-vectors, floats as SMT FPA, memory as SMT arrays pointer→byte, solver Z3, 1-minute/1 GB per query; going from 1 to 5 minutes raised proved-correct by <5%. 47 new LLVM bugs reported, 28 fixed. CompCert is "an alternative to translation validation" where "the compiler/optimizer is verified once and for all." Pnueli–Siegel–Singerman (1998) cited as early TV supporting only transformations that "did not change the control-flow or the loop structure." — [Alive2: Bounded Translation Validation for LLVM, PLDI 2021](https://www-old.cs.utah.edu/~regehr/alive2-pldi21.pdf).
- **Symbolic environmental bisimulation up-to (Koutavas, Lin, Tzevelekos; 2021–2022).** "A bounded equivalence verification technique for higher-order programs with local state … fully abstract symbolic environmental bisimulations … novel up-to techniques, and lightweight state invariant annotations … no false positives or negatives … bounded-complete, in that all inequivalences are automatically detected given large enough bounds" (tool Hobbit; proves all Meyer–Sieber examples) — [arXiv:2105.02541](https://arxiv.org/abs/2105.02541?context=cs). Bounded-completeness for *inequivalence* plus unbounded proof for *some* equivalences is the realistic shape of any equivalence checker over unbounded-data programs.
- **GKAT (Smolka, Foster, Hsu, Kappé, Kozen, Silva; POPL 2020).** "In contrast to KAT, whose equational theory is PSPACE-complete, we show that the equational theory of GKAT is (almost) linear time." Automaton model: G-coalgebra with G X = (2 + Σ × X)^At — each state, given an atom (a complete Boolean assignment to the tests), either accepts, rejects, or outputs an action and moves; GKAT expressions yield *deterministic* automata of size O(|e|) where KAT may need O(2^|e|). Completeness is Salomaa-style: the loop rule (W3) requires a productivity side condition E(e) ≡ 0, "without it, the rule is unsound"; general completeness is relative to a unique-fixpoint axiom; normal coalgebras forbid transitions into dead states — [GKAT, arXiv:1907.05920 / POPL 2020](https://arxiv.org/pdf/1907.05920.pdf). A later note on cyclic proofs / completeness is at [Kozen et al., Cyclic.pdf](https://cs.cornell.edu/kozen/Papers/Cyclic.pdf) and a 2024 follow-up at [Springer LNCS 2024, ch. 14](https://link.springer.com/chapter/10.1007/978-3-031-63501-4_14) (search results, not fetched).

### Inferences
- GKAT is structurally a Form: tests = guards of §6.4, actions = guarded updates, atoms = complete truth assignments to the guard predicates, and the G-coalgebra is deterministic — the same adjectives as T1/T2. If RCE's step bodies are projected to GKAT by treating every guarded update as an uninterpreted action and every guard as a test, then (a) equivalence of two such projections is decidable in nearly linear time, (b) the projection's deterministic automaton of size O(|e|) minimized is a canonical form of the *control skeleton*. This is the cheapest decidable canonical form available, and it is exact for what it models (uninterpreted actions). It is *not* exact for behavior: two bodies that differ only in arithmetic that happens to be equal are distinct in GKAT.
- Alive2 is the model for RCE's §5.2 ("every rewrite proved in Z3") at the next level up: proving that a *whole step* refines another, bit-vector-exact, within RCE's bounds. Because δ is total with a Lean-proved step bound B_P and loops carry explicit bounds, RCE does not need Alive2's loop-unroll approximation in principle — the unroll factor is LOOP_LIMIT — but 10⁶ unrollings are far beyond what Z3 handles; in practice a small symbolic bound plus an inductive invariant is the only route, and the paper's data (1→5 min buys <5%) says timeouts are structural, not tunable.
- Relational verification (product programs, Lean/Coq bisimulation proofs) is the route for the equivalences that matter but are not decidable cheaply; RCE's "model proposes, prover admits" (§5.5) already fits: the proposal is a candidate relation, the admission is an SMT/Lean proof. The admission step should be bisimulation on the product Form, not trace equality on sampled logs.

### Gaps
- I did not fetch NetKAT canonical/normal-form results (Foster et al. 2015 "A Coalgebraic Decision Procedure for NetKAT", POPL 2015) or Bonchi–Pous HKC (POPL 2013, "Checking NFA equivalence with bisimulations up to congruence"); both are standard and should be cited by the writer as the state of the art for exact automata equivalence up to congruence.
- No source was fetched on CompCert's exact proof technique (forward simulation diagrams, Leroy 2009); the Alive2 paper only contrasts it at the level of "verified once and for all."

## Key Question 4: Limits — Rice's theorem, bounded vs unbounded decidability, cost at 2^64 per field, decidable fragments

### Takeaway
RCE's bounds move every behavioral question from undecidable (Rice; Griffiths 1968 for transducers; 2-counter encoding for symbolic transducers with registers) to decidable-but-intractable: equivalence of two bounded Forms is a finite problem over ≤ 256^(2^20) states per region, so "decidable" buys nothing. Tractability comes only from restricting *how* data is used (equality/order atoms: register automata; linear arithmetic over bit-vectors: SMT with exponential worst case; EUF: polynomial congruence closure), and from exploiting structure (treewidth, sparsity).

### Cited Findings
- **Undecidability upstream of bounds.** "General equivalence of finite state transducers is undecidable [Griffiths 1968]"; symbolic transducers with registers: equivalence undecidable "already for the single-valued case, through direct encoding of 2-counter machines" — [Veanes et al., POPL 2012](https://www.doc.ic.ac.uk/~livshits/papers/pdf/popl12.pdf). Rice's theorem (every nontrivial semantic property of programs is undecidable) is the general statement; not fetched, standard (Hopcroft–Ullman).
- **Decidable fragments and their costs (from the fetched sources).** SFA minimization is polynomial in states *times* the cost f(ℓ) of a satisfiability check in the predicate algebra; the minterm route is exponential in the number of moves — [D'Antoni–Veanes POPL 2014](https://microsoft.com/en-us/research/wp-content/uploads/2016/02/sfaMinimizationPOPL14.pdf). SFT equivalence O(n²·f(m)); with linear arithmetic over one free variable Fourier–Motzkin gives polynomial worst case — [Veanes et al., POPL 2012](https://www.doc.ic.ac.uk/~livshits/papers/pdf/popl12.pdf). Register automata over equality or dense order: Myhill–Nerode and unique minimal *well-typed* DRA; integer atoms with arithmetic "pathological" — [Bojańczyk–Klin–Lasota LICS 2011](https://www.cs.ox.ac.uk/people/bartek.klin/papers/lics11.pdf), [Li–Tang–Yen 2026](https://arxiv.org/pdf/2605.03535). Incompletely specified Mealy minimization NP-complete (Pfleeger 1973, cited in [arXiv:2206.10228](https://arxiv.org/pdf/2206.10228)).
- **Explicit/BDD scale ceiling.** 4.2×10⁹ states → 5.4×10⁴ s on 2006 hardware, 2 GB — [Sigref ATVA 2006](https://ira.informatik.uni-freiburg.de/~wimmer/pubs/wimmer-et-al-atva-2006.pdf).
- **SMT ceiling in a production checker.** Z3 at 1 min/1 GB; 5× more time yields <5% more proofs — [Alive2 PLDI 2021](https://www-old.cs.utah.edu/~regehr/alive2-pldi21.pdf).
- **GKAT vs KAT.** GKAT nearly linear; KAT PSPACE-complete — [GKAT POPL 2020](https://arxiv.org/pdf/1907.05920.pdf).

### Inferences
- Decidability boundary in RCE's own terms: (i) Σc alone (control, kinds, bools, bounded enums) → finite, small, exactly minimizable: canonical form exists and is cheap. (ii) Σc + Σd used only via `==`, `<` on fields and payloads (no arithmetic into state) → the well-typed-DRA/orbit-finite fragment: canonical minimal machine exists and is computable, but *only* if the checker can recognize the fragment syntactically (a "data-only-compared" effect). (iii) Σc + Σd with i64 arithmetic → finite by N9 but the only honest claim is "equivalence is decidable in time exponential in VALUE_LIMIT"; practical procedures are SMT bit-vector proofs per pair (Alive2 shape) or e-graph rewrites (Q5), both incomplete. (iv) Floats: equivalence is still decidable (finite) but RCE forbids every float rewrite (N-8), so the canonical form of a float expression is its syntax.
- Presburger is decidable (triply exponential worst case, standard, not fetched); EUF is decidable in near-linear time by congruence closure (which is exactly what an e-graph implements); fixed-width bit-vectors are decidable (NEXPTIME-complete for the quantifier-free theory with binary-encoded widths, standard, not fetched). RCE's checked-overflow i64 semantics means a rewrite must be proved *with* the overflow trap as part of the output alphabet O\* — Alive2's poison/UB-aware refinement is the precedent: the trap is an observable output, so the equivalence relation is on (state, O\*) pairs including `trap`, not on values alone.
- Cost of "minimization when state is 2^64 per field" is the wrong question to ask; the right one is "what is the coarsest *predicate* abstraction of the i64 field under which δ is still deterministic and total on abstract states" — if such an abstraction exists with k predicates, minimization costs O(2^k log 2^k · f(…)) by D'Antoni–Veanes and is unique up to predicate equivalence. If none exists (the field is genuinely a counter), no finite-control canonical form exists below the full 2^64 and the only canonical object is the *term* δ itself, i.e. syntax.

### Gaps
- No single source fetched gives complexity bounds for equivalence of *bounded* (fuel-limited) programs as a function of the bound; it follows from finiteness (PSPACE in the bit size of the state for succinctly represented systems, standard) but I did not locate a citation specific to fuel-bounded transition systems.

## Key Question 5: E-graphs and equality saturation as partial canonicalization

### Takeaway
An e-graph decides exactly the EUF congruence closure of the equalities it has been given, extended by whatever rewrites were fired; it never decides equivalence in general (saturation may not terminate; rewrites are user-supplied; proofs are needed per rule, which RCE already does in Z3). Extraction under a DAG cost model is NP-hard and inapproximable within any constant factor unless P=NP (Goharshady–Lam–Parreaux, OOPSLA 2024 per secondary source); it is polynomial for tree cost and fixed-parameter tractable in treewidth 2^O(w²)·poly(w,n) (Sun–Zhang–Ni 2024). So "the smallest term in the e-class" is a canonical representative only under tree cost, and under DAG cost only via an exact solver.

### Cited Findings
- **egg (Willsey, Nandi, Wang, Flatt, Tatlock, Panchekha; POPL 2021, arXiv 2004.03082).** "An e-graph efficiently represents a congruence relation over many expressions"; contributions are *rebuilding* (amortized invariant restoration) and *e-class analyses* — [egg, arXiv:2004.03082](https://arxiv.org/abs/2004.03082). The abstract does not address termination of saturation or extraction optimality.
- **egglog (PLDI 2023)** combines equality saturation with Datalog — per [Chugh 2026 blog](https://mohakchugh.is-a.dev/blog/egraph-extraction-dag-cost-cycles-treewidth) (secondary; primary: Zhang et al., "Better Together: Unifying Datalog and Equality Saturation", PLDI 2023 — not fetched).
- **Extraction hardness and tractable cases.** "DAG-cost extraction was shown NP-hard in Stepp's 2011 dissertation"; Goharshady, Lam, Parreaux (OOPSLA 2024, "Fast and Optimal Extraction for Sparse Equality Graphs") showed extraction is "hard to approximate to any constant factor"; tree cost is polynomial and optimal via bottom-up fixpoint; the greedy DAG extractor "fails most where sharing is high"; exact ILP with big-M acyclicity "does not scale well on large graphs"; SmoothE (ASPLOS 2025) differentiable relaxation 8–37× faster than ILP on 4/5 datasets; e-boost (ICCAD 2025) 558× over exact ILP with 19% quality gain over SmoothE — [Chugh, E-Graph Extraction: The NP-Hard Step Everyone Skips, 30 Jul 2026](https://mohakchugh.is-a.dev/blog/egraph-extraction-dag-cost-cycles-treewidth) (secondary; primary OOPSLA 2024 page at [Parreaux publication page](https://cse.hkust.edu.hk/~parreaux/publication/oopsla24a/) redirected and was not fetched).
- **E-graphs as circuits (Sun, Zhang, Ni; arXiv 2408.17042, Aug/Nov 2024).** "We demonstrate a new connection between e-graphs and Boolean circuits"; optimal extraction in "2^{O(w²)} poly(w, n) time, where w is the treewidth of the e-graph"; simplification reduces "e-graph size and treewidth by 40-80% in many cases" — [E-Graphs as Circuits, and Optimal Extraction via Treewidth](https://arxiv.org/abs/2408.17042). SmoothE primary: [SmoothE, ASPLOS 2025](https://www.csl.cornell.edu/~yc2632/data/smoothe_asplos2025_final.pdf) (search result, not fetched).
- **Rewrite admission in RCE today.** Paper §5.2: "Every built-in e-graph rewrite is proved in the Z3 SMT solver … A proposed equivalence enters the e-graph only with a proof"; §5.5: of 16 model proposals, 3 admitted, 13 rejected — RCE paper (fetched, grounding).

### Inferences
- What an e-graph *is*, in RCE terms: a decision procedure for "t₁ = t₂ under the admitted rule set plus congruence", i.e. EUF closure. It is complete for EUF and for any theory whose rules it has saturated; it is not a decision procedure for i64 equivalence (no finite rule set is complete for bit-vector arithmetic in general) and therefore the e-class of a step body is a *lower bound* on the true equivalence class. This is exactly "partial canonicalization": two bodies in one e-class are provably equivalent (sound, since every rule is Z3-proved); two bodies in different e-classes are *not* known to differ.
- A canonical representative of an e-class exists only under a cost model that makes extraction unique: tree cost with a deterministic tie-break on canonical JSON is unique and cheap; DAG cost requires an exact extractor and is NP-hard. For a *shape hash* purpose, tree-cost extraction with canonical-JSON tie-break is the right choice — the hash does not need to be the cheapest term, only a deterministic one. form-ir-2's opaque `ref` leaves and INLINE_MAX bound are consistent with this: they keep e-graph size bounded so extraction stays tractable.
- Non-termination of saturation is a real operational hazard (associativity/commutativity blow-up); RCE already bounds everything else — the e-graph should get the same treatment: a node budget and iteration budget, with the resulting e-class relation declared *as of* that budget and hashed with the budget (otherwise the "canonical" hash is not reproducible across engines).

### Gaps
- Primary texts for Goharshady–Lam–Parreaux (OOPSLA 2024) and egglog (PLDI 2023) were not fetched; the hardness/inapproximability statement is from a secondary source and should be verified against the OOPSLA paper.
- No source found on *canonical* (rather than optimal) extraction — the uniqueness of extracted term under tie-breaking is an inference.

## Recommendations in RCE's own terms (adopt / refuse / open)

### Adopt
1. **Three-tier shape hash, each tier named in the hash.** (a) `shape_syn`: today's hash — SHA-256 of canonical JSON of the name-free (De Bruijn) term; injective on Forms (paper §3.6), T7 name-free. (b) `shape_ctl`: SHA-256 of the Reis–Moreira–Almeida canonical string of the *minimal* deterministic complete Mealy machine obtained by quotienting Σc with Σd abstracted to the guard predicates of §6.4, states numbered by first-visit traversal from s₀ with events in the canonical order of §6.1 and outputs appended per transition; predicates hashed by a canonical form (BDD under a fixed variable order for bit-blasted guards; otherwise the e-class representative of the predicate). Unique up to predicate equivalence (D'Antoni–Veanes Thm 1); decidable; cost O(n² log n · f(nℓ)) in Z3 calls. (c) `shape_eq`: SHA-256 of the tree-cost, canonical-JSON-tie-broken extraction of the body's e-class after saturation under the admitted rule set *with the saturation budget included in the hashed input*. Each tier is a coarser equivalence; equality at any tier implies behavioral equivalence (soundness) and inequality implies nothing.
2. **Define behavioral equivalence as bisimulation on the product Form over (S, O\*) with `trap`/`Refused` as outputs**, not as equality of sampled logs. This is the relation Alive2 calls refinement when UB is absent and is what the Lean side should state T50's converse against.
3. **Project step bodies to GKAT** (guards → tests, guarded updates → uninterpreted actions). Use the nearly-linear GKAT decision procedure as the first, cheap equivalence check and its normalized deterministic automaton as `shape_ctl` for the uninterpreted fragment.
4. **Recognize the register-automaton fragment syntactically**: a region whose data fields are only compared (`==`, `<`) and copied, never computed on, is a well-typed DRA; its minimal machine is unique (Benedikt–Ley–Puppis via Li–Tang–Yen) and `shape_ctl` is exact behavior for it. Emit a diagnostic naming which field's arithmetic breaks the fragment.
5. **Keep every e-graph rewrite Z3-proved with the overflow trap in the output alphabet**, and keep floats syntactic (N-8). Bound e-graph size and iterations like LOOP_LIMIT; publish the budget as part of the e-class identity.
6. **Treat acyclic control (loop bounds that unroll the control graph into a DAG) specially**: rank-based canonical numbering (MADFA style) is cheaper and gives the same uniqueness.

### Refuse
1. **"The minimal machine is *the* canonical form of a Form."** False as a computable claim for Σd with arithmetic (|S| up to 256^(2^20); SFT-with-registers equivalence undecidable before bounds, intractable after). State it only for the Σc-plus-predicates projection.
2. **Hashing a DAG-cost-optimal extraction as canonical.** NP-hard and inapproximable; non-reproducible across extractors. Tree cost with canonical tie-break only.
3. **Equivalence by differential trace testing as evidence of canonical identity.** The paper already says §5.1 "says nothing about inputs outside them"; keep it as a test, never as a hash input.
4. **Any float rewrite in the equivalence relation** (N-8 already).
5. **Letting a model's proposal change an e-class without a proof** (already refused, §5.5) — and, by extension, letting a model's proposed *predicate abstraction* define `shape_ctl` without Z3 proving the abstraction is a bisimulation.

### Open problems (for RCE specifically)
1. **Converse of T50**: for which fragment does equal meaning imply equal `shape_ctl`? Conjecture: exactly the GKAT-plus-well-typed-DRA fragment; needs a Lean statement and proof that the predicate-abstracted quotient is a bisimulation of the concrete Form.
2. **Canonical form of guard predicates over i64 with checked overflow**: BDD after bit-blasting is canonical but 64-bit wide; LIA normal forms are not unique. Which to standardize so `shape_ctl` is reproducible across engines?
3. **Whether VALUE_LIMIT/LOOP_LIMIT changes `shape_ctl`**: the quotient of a bounded machine can differ from that of a larger-bounded one (T15 only says runs are prefixes). The hash must either include the bounds or be proved bound-independent for the fragment.
4. **Register/state trade-off**: Li–Tang–Yen show minimal DRAs need not exist when registers trade off against states. RCE's regions fix the registers (fields) by declaration, which may restore uniqueness — unproved.
5. **Non-termination of saturation vs reproducibility**: a budgeted e-class relation is reproducible only if the rewrite scheduler is deterministic across engines; that is an engineering invariant RCE has not stated.
6. **Workflow-level canonical form**: nothing in 2023–2026 literature; RCE's SCXML/XState emitters make a published result possible but none exists.
