# Surveys of 22 October 2026

Three literature surveys read against the public RCE repositories, cited by
the RCE paper (section 12). Each report is a synthesis; the `notes/`
directories hold the per-topic working notes it was written from, with the
sources each note read and the ones it could not reach.

| Report | Question | Notes |
|---|---|---|
| `what-rce-should-be.md` | What the state of the art in seven areas (canonical forms, content-addressed intermediate representations, partial-order semantics, synthesis from intent, energy cost models, languages for machine authors, proof engineering) says the Form should be | `notes/what-rce-should-be/` |
| `the-geometry-of-code-atlas.md` | Where the Form sits among about a hundred programming languages placed on eight coordinates, and which constraints the record imposes | `notes/geometry-of-code-atlas/` |
| `why-human-code-is-noisy.md` | The measured causes of redundancy in human-written code and what the Form, the projection and the governance absorb | `notes/why-human-code-is-noisy/` |

Evidence grading used throughout: *measured* means read with numbers from
the source; *canonical, not fetched* means a primary source cited from
prior knowledge and to be treated as attribution, not verified quotation;
*vendor* means industry data with undisclosed sampling.
