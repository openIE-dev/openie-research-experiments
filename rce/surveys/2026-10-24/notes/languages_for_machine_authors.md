# Catalogue: languages / IRs / code substrates for or by AI agents (Jan 2024 – Oct 2026)

**Method.** agentlanguages.dev itself is unreachable from this sandbox, but its source repo (github.com/aallan/agentlanguages, created 2026-05-20, MIT/CC-BY-4.0, maintained by Alasdair Allan) is. I read all 48 entry files in `src/content/languages/*.md` (the site says 48 as of 22 Oct 2026, up from the 42 you cited) plus `src/data/stars.json`, then fetched each project's GitHub page and pulled created_at / pushed_at / stars / licence via the GitHub search API for 60 repos. I then searched HN, lobste.rs, arXiv, GitHub topics and language-announcement posts for entries beyond the catalogue; 24 extra rows follow the catalogue rows. HN, dev.to, arxiv.org, lucumr.pocoo.org and hn.algolia.com were not fetchable; facts from them are via search snippets and are marked (snippet).

**Mechanism key** (per row, in this order): CF = one canonical form/IR as source of truth · DET = deterministic evaluation across machines · REF = refusal of invalid input at boundary · EX = examples/tests part of the program · HASH = hash-identified definitions/content addressing · LOG = append-only log or replay · MS = memory safety without GC · EMIT = compiles/emits to other languages · LIFT = imports/lifts code from other languages · SPEC = formal specification or proofs. Values: y / n / u (unclear/not stated). "(sr)" = self-reported claim by the project, not independently checked. "Status" = repo created → last push, stars (GitHub API, 24 Oct 2026), size/LOC where stated, maintainers.
