# Working note 6: new general-purpose and systems languages, January 2024 to October 2026, and the positions they converge on

Written 24 October 2026. Sources reached: GitHub repository, release and commit pages, GitHub repository search (`created:>2024-01-01`), and search extracts of LWN, InfoQ, the Racket blog, Habr, Hackaday and project blogs. Not reachable: en.wikipedia.org, Hacker News, codeberg.org and nearly every project website (ziglang.org, roc-lang.org, odin-lang.org, flix.dev, gleam.run and others); where a site was unreachable the GitHub README and search extracts were used. Position codes: P1 memory safety without a garbage collector; P2 deterministic or reproducible evaluation; P3 effect tracking or capability-based I/O; P4 no shared mutable memory between threads; P5 compiles or emits to another language; P6 an interchange or intermediate form as the source of truth; P7 examples or tests inside the program; P8 hash or content-addressed definitions; P9 a written specification or formal semantics; P10 proofs in a proof assistant. "(sr)" marks a self-reported claim. Stars as shown on GitHub on 24 October 2026. Languages primarily for machine authors are in working note 5 and excluded here (Vera, Sui, Mog, Sigil, Jacquard, Corvid).

## The five positions most entries share

1. Compile or emit to another language (C, Go, WebAssembly, JavaScript, Bash, C++, Scheme, Erlang): 17 of 39 new, 32 of 74 overall. Go is the target of 2026 (Lisette, Sky, Soppo, Gauntlet, Borgo); C remains the systems default.
2. A written specification in the repository as the authoritative definition: 14 of 39 new; the AI-assisted projects (Rue, Dawn, Gossamer, Hexa, Cursed) all ship one and describe the test suite as checked against it.
3. Memory safety without a garbage collector: 7 of 39 new, 14 of 74; the 2025 to 2026 cohort converges on Perceus-style precise reference counting (Wyzer, Gossamer, Dawn; earlier Koka, Lean) or ownership and affine schemes (Rue, Valen, Zeta) rather than lifetime annotations; Goose's data stacks are the outlier.
4. Effect tracking or capability-based I/O: 4 of 39 new, 11 of 74; Cangjie's effect handlers (2026) are the first industrial adoption in the set.
5. No shared mutable memory between threads: small but consistent among the parallel-by-construction designs (Bend, Goose, Flix, Gossamer, Plush).

An intermediate form as the source of truth is essentially absent from the new languages (Unison and Jule, both older, take it); tests inside the program remain rare (Dawn, Soppo, C3, Nature); deterministic evaluation as a stated release gate appears in three new languages (Gossamer, Dawn, Wyzer).

## Other findings

- Languages built largely by model agents and disclosed as such: Goose, Rue, Cursed, Jolt; Gossamer, Dawn, Hexa, Sky and Rad ship CLAUDE.md, AGENTS.md or an AI policy; Kairo forbids AI-written compiler code. Self-reported benchmark claims (Goose faster than C++ and Rust) were flagged by lobste.rs commenters and are unverified.
- Conflicting records: Zeta's version history; Fun's implementation language; Lisette's first date.
- Dormant or ended in the window: Vale (archived), Wing, Borgo, Scrapscript, Otterlang, the old Hylo compiler.
- Milestones announced and not reached: MoonBit 1.0, Roc 0.1, Carbon 0.1, Valen 0.1, Wyzer 0.1, Hare 1.0.
- Conference sweep (PLDI, OOPSLA, POPL, ICFP, ECOOP 2024 to 2026): Cangjie (PLDI 2025 talk), Fram (ICFP ML Workshop 2024), Fearless (arXiv 2024), Effekt (OOPSLA 2025), Verus (SOSP 2024); no other new general-purpose language with a public implementation.
