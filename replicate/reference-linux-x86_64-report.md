## 5. Limitations & What This Harness Does *Not* Test

1. **No Live Cloud LLM Calls:** Suite 1 measures local content-addressed lookup determinism and prompt serialization/tokenization overhead; it does not re-execute proprietary cloud LLM APIs (`Claude`, `GPT`, `Grok`).
2. **On-Chip Counter vs. Wall Shunt (`reported_j` != `measured_j`):** When Linux `powercap`/`RAPL` is readable without root, figures are reported strictly as `reported_j` (socket/package counter, subject to shared-host background activity) and never conflated with inline DC/AC shunt `measured_j`. When unreadable (unprivileged Docker or macOS without root), `joules` is `null` (`unmetered`).
3. **Independent Disagreement Welcome:** Hardware microarchitectures, OS governors, Python builds, and C/Rust compiler versions shift `N*` break-even horizons and parse ratios. Please submit both confirming and falsifying runs via GitHub Issues/PRs with `replication-report.json` attached.
