# Agency run: preregistration

Fixed and committed before the pilot and before the main run. The analysis is `analyze.py` as committed with this file. Nothing below changes after the commit.

## Question

An acceptor agent closes Sudoku tasks under binding joule budgets. Each act has a predicted result fixed before it, a comparison after it, and refusal with a receipt. Two selectors use the same information, gears, predicate, budget and meter. A goal-blind agent is the baseline. We read confirmed coupled bits X and joules J per run, the intelligence iota = dX/dJ, J* per task, and the ranking.

## Machine and meter

- Apple silicon laptop (Apple M5 Max, 18 cores, 128 GB), macOS, on AC power. Python 3 standard library only.
- Joules per act and per episode: `ri_energy_nj` from `proc_pid_rusage(RUSAGE_INFO_V6)` for the agent process. The kernel computes it from its energy model. Label: `reported_j`. The agent boundary is the process.
- Cross-check: `sudo -n powermetrics` (non-interactive) over fixed windows, CPU, GPU and ANE (Apple Neural Engine) power. Apple describes these values as estimates. Label: `reported_j`. Gross and idle-subtracted figures are both reported.
- `measured_j` is empty. No external wall meter reading exists.
- `est_j` = cycles x c, with c the median ratio of reported joules to cycles over all pilot acts, locked after the pilot.

## Tasks and predicate

- `tasks/test.json`: 30 puzzles, 10 per stratum (easy, medium, hard), generated by `gen_tasks.py` with seed 8102026. `tasks/calib.json`: 30 puzzles from seed 20261008, used only for the selectors' calibration table.
- Completeness predicate C(z): the grid is full, every row, column and box holds 1 to 9, and every given is kept.
- Coupled bits of a confirmed task: b = (empty cells) x log2 9. This is log2 of the number of fills the act chooses among: the capacity bound of Definition 1 for an actuator that can write any fill. X counts b only when C(z) passes within the budget.

## Gears

g0 naked singles; g1 naked and hidden singles; g2 g1 plus depth-first search on the cell with fewest candidates, branch order drawn from the run's seeded generator. Each gear checks the meter during its work and aborts when spent + 2 x (largest step so far) + 0.05 B reaches B.

## Arms

1. **sigma-law selector.** Among untried gears whose calibrated cost fits the remaining budget, choose a* = argmax [H(a) - lambda J(a)], with H(a) = p(a passes | tried gears failed) x b and J(a) the calibrated cost. lambda = b / B (bits per joule of budget). Refuse with a receipt when no gear fits or the best value is not positive.
2. **Mixture of Limits cheapest-sufficient rule.** Among untried gears in order of cost, choose the cheapest with p(a passes | tried gears failed) >= 0.5; if none, the one with the highest p. Refuse with a receipt if it would break the remaining budget.
3. **Goal-blind baseline.** One gear drawn uniformly at random. No predicted result, no comparison, no escalation, no refusal. The budget is a hard cutoff for it. Its output is scored by C(z) after the episode, outside its joules.

Both selectors see the same feature: the bin of the empty-cell count (at most 50, 51 to 55, 56 or more). p uses the Laplace rule on the calibration table. Law-abiding arms fix R* = {task, gear, predict C(z)=1, predicted joules, budget left}, hash it with SHA-256 and timestamp it before the act. m = 1 when C(z) passes. On m = 0 the agent escalates or refuses.

## Pilot

Every gear alone on every calibration puzzle, 5 repetitions, unbudgeted: per-bin median cost and the pass table. g2 alone on every test puzzle, 5 repetitions: the median J_g2(q) that sets budgets. The pilot output is committed as `pilot/locked.json` before the main run.

## Main run

- Budgets per task: B in {0.5, 1.0, 2.0} x J_g2(q). A level binds if at least 20% of pilot g2 runs exceed it.
- 20 seeds. Per seed, the 9 conditions (3 arms x 3 levels) run in a seeded random order. Task order within a run is shuffled by seed. One unrecorded warm-up pass runs first. The garbage collector is off inside each metered run.

## Quantities

- Per run: X (bits), J (reported joules, sum of episodes), iota = X / J (bits per joule). Mean and standard deviation over seeds.
- Per act: iota_k = b_k / J_k for confirmed acts. Distance to floor: (J_k / b_k) / (k_B T ln 2) at T = 300 K.
- J*(q): joules of the episode when C(z) passes, infinity otherwise. Per task, the median over seeds.
- Ranking by J*: more tasks with a finite median J* ranks higher; ties broken by the sum of median J* over tasks every arm closes. Ranking by integrated iota: the mean run iota.

## Falsifiers

| ID | Observation | Claim defeated |
|---|---|---|
| R-F1 | At every binding level, the 95% bootstrap interval of the paired per-task difference in median J*, sigma minus Mixture of Limits, over tasks both close, includes or exceeds zero | The sigma-law selector closes tasks in fewer joules than Mixture of Limits |
| R-F2 | Any episode in any arm ends with J above its budget | That arm's budget enforcement and refusal |
| R-F3 | Refusal recall below 0.9 on task-level pairs no arm ever closes, or more than 10% of law-arm refusals on pairs some arm closes in at least half the seeds | Refusal correctness |
| R-F4 | Kendall's tau-b between est_j and reported_j per act below 0.8 | The cycle-count estimator for any ranking |
| R-F5 | Coefficient of variation of run iota across seeds above 0.25 in any condition | Reading iota at run granularity in that condition |
| R-F6 | Ranking by J* differs from ranking by integrated iota at any level | Ranking by J* equals ranking by integrated iota |
| R-F7 | Any confirmed act with reported joules per bit below k_B T ln 2 | The accounting |
| R-F8 | At a binding level the goal-blind mean run iota is at least the larger of the two selectors' | Prediction first, comparison and refusal raise iota over a goal-blind agent |

Every falsifier outcome is reported, fired or not, with the same prominence.
